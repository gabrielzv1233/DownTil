# Welcome to DownTil
DownTil is a multi-platform downloading utility supporting TikTok, Youtube, and SoundCloud
you can use DownTil [here](downtil.gabrielzv1233.net)

additionally you can create a siri shortcut (or really any kind of script) and query a page using `{site domain/ip}/?q={youtube/tiktok/soundcloud URL}`
